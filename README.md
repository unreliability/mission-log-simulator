# 🚀 Mission Log Simulator

A lightweight tool for generating realistic spacecraft mission telemetry logs.

## Overview
This project simulates mission telemetry (e.g. temperature, voltage) over time and can inject controlled anomalies such as voltage drops. It is intended for testing telemetry pipelines, ground systems, and anomaly detection algorithms.

## Features
- Configurable sensors
- Time-based simulation
- Anomaly injection
- CSV and JSON outputs

## Example Use Case
- Testing mission control dashboards
- Validating data ingestion pipelines
- Prototyping anomaly detection systems

## Status
Early prototype / concept project.

## Roadmap
- Additional anomaly types
- Streaming telemetry output
- More realistic mission profiles
